# 任务

从一条中文职业任务 query 中提取用于检索支持文件的关键词或短语。

# 提取原则

1. 只依据当前 query 提取，不使用预设题型、固定行业分类或外部知识补充主题。
2. 只保留能够显著区分本题的对象、业务活动、证据类型、风险事件、规则关系和
   判断条件。关键词组合应能代表这道题独有的检索方向。
3. 忽略岗位称谓、礼貌用语、通用任务指令、交付格式和准确性声明，除非它们
   本身决定了所需文件类型。
4. 提取 5 至 8 个互补的中文关键词或短语。宁可少而准确，不要为了覆盖 query
   的每个分句凑满数量。若一个词会命中大量与本题无关的通用金融材料，就不要
   单独选用它。
5. 如果 query 中多个特征足以唯一指向一个业内通用概念，可以把它规范化为该
   概念的常用称谓或同义检索词；这种扩展必须能由 query 本身可靠推导，不能靠
   猜测补充新的题目方向。
6. 不得添加 query 中没有依据的公司、机构、年份、金额、比例或结论。

# 输出

只输出一个 JSON 对象，格式严格为：

{"keywords": ["关键词一", "关键词二"]}

不要输出 Markdown、解释或其他字段。
