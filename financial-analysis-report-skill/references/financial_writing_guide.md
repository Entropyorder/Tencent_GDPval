# 财务分析自然写作指南

## 一、基本分析链

每个重要结论按以下顺序展开：

1. **结论**：指标改善、承压、稳定或存在结构性分化。
2. **证据**：使用 1—3 个关键数字证明结论。
3. **原因**：解释客户、产品、产能、价格、成本、费用、回款或投资活动。
4. **边界**：指出一次性因素、口径限制和未来不确定性。
5. **行动**：给出责任对象明确、可执行的管理建议。

## 二、推荐句式

- “收入与利润同步改善，说明本期增长并非单纯依赖规模扩张。”
- “毛利率提升主要来自产品组合优化和单位制造成本下降，但价格年降仍可能压缩后续改善空间。”
- “流动比率有所提高，但应收账款和存货占比较高，账面流动性与可动用现金仍存在差异。”
- “经营现金流覆盖净利润，利润具有较好的现金实现基础；资本性支出较高，自由现金流仍为负。”

## 三、需要避免的模板腔

### 不自然

> 由上表可知，公司营业收入同比增长 11.0%，净利润同比增长 27.7%，说明公司经营情况良好。

### 改写

> 本期收入增长 11.0%，净利润增幅达到 27.7%，利润增速明显快于收入。结合毛利率和费用率变化看，改善主要来自产品结构优化及固定费用摊薄，而不是单纯扩大销售规模。

### 不自然

> 公司应加强应收账款管理，提高资金使用效率。

### 改写

> 建议按客户建立合同金额、验收、开票和到账四个节点的回款台账，对逾期超过约定期限的项目暂停新增信用额度，并在月度经营例会上由销售负责人说明偏差原因和回收计划。

## 四、用词边界

- 不使用“显著”“大幅”“非常”等词替代数据；除非变化幅度和业务事实足以支持。
- 不把相关性写成因果关系。无法确认原因时写“可能与……有关”或“需要结合……进一步核实”。
- 不将单期改善直接外推为长期趋势。
- 不写“总体来看发展前景良好”等空泛结尾。
- 不伪造行业均值、预算值、审计结论、管理层访谈或外部数据来源。

## 五、表格与正文的关系

正文不逐行复述表格。表格用于完整呈现数据，正文只选取最能支撑判断的指标，并说明指标之间的关系。例如：收入增速、净利润增速、毛利率和经营现金流应放在同一分析框架内，而不是分成四句独立陈述。
